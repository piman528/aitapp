# 技術コンテキスト

## 開発環境
- Flutter SDK
- Dart
- Android Studio / VS Code
- iOS Simulator / Android Emulator

## 主要依存関係
```yaml
dependencies:
  flutter:
    sdk: flutter
  provider: ^6.0.0  # 状態管理
  freezed: ^2.0.0   # イミュータブルオブジェクト
  sqlite3: ^1.0.0   # ローカルデータベース
  http: ^0.13.0     # HTTP通信
  shared_preferences: ^2.0.0  # 永続化ストレージ
```

## アーキテクチャ要件
1. クリーンアーキテクチャ
   - 層の分離
   - 依存関係の一方向性
   - テスト容易性

2. 状態管理
   - Provider pattern
   - 反応的な更新
   - 状態の分離

3. データ永続化
   - SQLite
   - SharedPreferences
   - キャッシュ戦略

## 技術的制約
1. プラットフォーム要件
   - iOS 12.0以上
   - Android 5.0 (API 21)以上
   - メモリ使用量の最適化

2. ネットワーク
   - RESTful API通信
   - オフライン対応
   - 低速ネットワーク対応

3. セキュリティ
   - HTTPS通信
   - データの暗号化
   - セキュアストレージ

## インフラストラクチャ
1. バックエンド連携
   - 大学システムAPI
   - Moodleインテグレーション
   - 認証サーバー

2. ストレージ
   - ローカルDB (SQLite)
   - キャッシュ
   - セキュアストレージ

3. 外部サービス
   - プッシュ通知
   - マップサービス
   - PDFビューワー

## パフォーマンス要件
1. 応答性
   - アプリ起動時間 < 2秒
   - 画面遷移 < 300ms
   - API応答 < 3秒

2. リソース使用
   - メモリ使用量 < 100MB
   - ストレージ < 50MB
   - CPU使用率の最適化

3. オフライン性能
   - 基本機能の維持
   - データ同期の効率化
   - ネットワーク再接続時の回復

## 開発プラクティス
1. コード品質
   - Dartの静的解析
   - コードフォーマット
   - ドキュメンテーション

2. テスト
   - 単体テスト
   - ウィジェットテスト
   - 統合テスト

3. CI/CD
   - 自動ビルド
   - 自動テスト
