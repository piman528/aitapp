# プロジェクト概要

## 目的
大学生活支援のためのFlutterモバイルアプリケーションの開発。

## 主要機能
- シラバス検索・閲覧
- 時間割管理
- キャンパスマップ
- お知らせ通知
- スケジュール管理
- 交通機関情報（バスの時刻表など）
- 学内施設へのコンタクト情報

## 技術スタック
- Flutter/Dart
- RESTful APIとの連携
- SQLiteデータベース（時間割用）
- PDF表示機能
- WebView統合

## プロジェクトゴール
1. 学生の日常的な学習・生活活動の効率化
2. 大学からの重要な情報へのアクセス改善
3. キャンパスライフのデジタル化促進
4. シームレスな情報アクセスの実現

## 品質要件
- 高いパフォーマンス
- オフライン対応
- データの整合性
- ユーザーフレンドリーなインターフェース
- セキュアな認証システム
